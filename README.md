# agent-game-framework

Installable Python framework for playing turn-based/simultaneous-move games
with any mix of human and AI-controlled seats. See `docs/PLAN.md` and
`docs/adr/` for the design; `CLAUDE.md` for day-to-day workflow.

**Status:** package skeleton only (`KAN-1274`) — no game engine yet.

## Install (editable, for development)

```
uv sync --all-extras --dev
```

or, from a plain venv:

```
pip install -e .
```

## Usage

```
agf --help
```
